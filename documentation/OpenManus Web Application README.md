# OpenManus Web Application

This is the web interface component of the OpenManus project, providing a user-friendly interface that allows users to interact directly with the OpenManus AI assistant in their browser.

![OpenManus Web Interface](../assets/interface.png)

## Key Features

- 🌐 Modern web interface with real-time communication support
- 💬 Intuitive chat interface for asking questions and receiving AI responses
- 🧠 Visualized thinking process, displaying each step of the AI's reasoning
- 📁 Workspace file management to view and manage files generated by the AI
- 📊 Detailed log tracking and monitoring
- 🚀 Support for interrupting and stopping ongoing requests

## Technology Stack

- **Backend**: FastAPI, Python, WebSocket
- **Frontend**: HTML, CSS, JavaScript
- **Communication**: WebSocket for real-time communication
- **Storage**: File system for storing generated files and logs

## Quick Start

1. Ensure all dependencies are installed:

```bash
pip install -r requirements.txt
```

2. Start the web server:

```bash
python web_run.py
```

Or from the project root directory:

```bash
python main.py --web
```

3. Open your browser and visit: http://localhost:8000

## API Endpoints

### Chat Related

- `POST /api/chat` - Create a new chat session
- `GET /api/chat/{session_id}` - Get results for a specific session
- `POST /api/chat/{session_id}/stop` - Stop processing for a specific session
- `WebSocket /ws/{session_id}` - Establish a WebSocket connection for a session

### File Related

- `GET /api/files` - Get all workspace directories and files
- `GET /api/files/{file_path}` - Get the content of a specific file

### Log Related

- `GET /api/logs` - Get a list of system logs
- `GET /api/logs/{log_name}` - Get the content of a specific log file
- `GET /api/logs_parsed` - Get a list of parsed log information
- `GET /api/logs_parsed/{log_name}` - Get parsed information for a specific log file
- `GET /api/latest_log` - Get parsed information for the latest log file
- `GET /api/systemlogs/{session_id}` - Get system logs for a specified session

### Thinking Process

- `GET /api/thinking/{session_id}` - Get thinking steps for a specific session
- `GET /api/progress/{session_id}` - Get progress information for a specific session

## Interface Description

The OpenManus Web interface is divided into two main sections:

1. **Left Panel** - Displays the AI's thinking process and workspace files
   - AI Thinking Timeline: Displays each step in the AI's processing
   - Workspace Files: Displays files generated by the AI, click to view content

2. **Right Panel** - Conversation interface
   - Conversation History: Displays the dialogue between the user and the AI
   - Input Area: Users can input questions or commands

## Local Development

1. Clone the repository
2. Install dependencies
3. Start the application in development mode:

```bash
uvicorn app.web.app:app --reload
```
Or
```bash
python web_run.py
```
